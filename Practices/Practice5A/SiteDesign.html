Butterflies and Moths Website - Color Palette

This page documents the color scheme used for the Butterflies and Moths website.

Color Scheme Details:

Background Color
#E8F5E1
Text Color
#2C5F2D
Link Color
#4A7C59
Visited Link Color
#6B8E23
Hover Link Color
#228B22

Usage Notes:

  • Background: Light green (#E8F5E1) - provides a natural, calming atmosphere
  • Text: Dark green (#2C5F2D) - good contrast for readability
  • Links: Medium green (#4A7C59) - distinct but harmonious with theme
  • Visited Links: Olive green (#6B8E23) - subtle distinction from unvisited links
  • Hover Links: Forest green (#228B22) - interactive feedback
